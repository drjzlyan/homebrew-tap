# drjzlyan/homebrew-tap

Homebrew formulae for [DHI](https://github.com/drjzlyan/dhi), the agentic workspace IDE.

```sh
brew install drjzlyan/tap/dhi   # install
brew upgrade dhi                # update to the latest release
```

`Formula/dhi.rb` installs the prebuilt, checksummed binary from each DHI
GitHub release (macOS 12+ and Linux, arm64 and x86_64). DHI's release
workflow updates it on every tagged release.
